## 🚀 Featured Projects

### 🏫 [Kigumo TVC Website & Portal](https://github.com/FranNMK/kigumo-TVC)
A full-stack college website and staff/student portal built with Node.js, Express, and TiDB — featuring course materials, timetables, and an admin dashboard. Live and used daily by 200+ students and staff.

### 🎙️ [SkillNarrate](https://github.com/FranNMK/SkillNarrate)
AI-guided interview platform that turns TVET and technical students' projects into polished professional outputs — case studies, LinkedIn posts, pitch scripts, and STAR-format interview answers — through a short adaptive conversation. Built for the **IBM AI Builders Challenge (Creative Industries)** using Next.js, Supabase, and Google Gemini 2.5 Flash via OpenRouter, with full Row Level Security and a public shareable portfolio for every student. Live at [skill-narrate.vercel.app](https://skill-narrate.vercel.app).
